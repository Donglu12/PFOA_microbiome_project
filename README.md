# PFOA Microbiome Analysis

This repository contains scripts used for QIIME2 processing and R-based microbiome analysis for the PFOA project.

## QIIME2 scripts
- qiime_PFOA.slurm
- assignment6_PFOA.slurm

## R analysis
- analysis.R

## Metadata
- sample-metadata.tsv

- qiime2_commands.sh: complete QIIME2 command record for sequence processing, diversity analysis, taxonomy, ANCOM-BC, and Random Forest classification
